# 我写故我播——一本 AI 犯过错的书

**边界的实测、缺陷的坐标与因地制宜的裁量**　·　v1.0.0　·　66 章 / 约 18.7 万字

> 播客智能体 podcast-maker 从空目录跑到能出片，路上踩了 47 个坑。这本书把每个坑的现象、错误尝试、根因、修法、验证原样留档；其中 13 个是 LLM 在执行过程中自己犯的错——错出现的形状和位置，就是边界的坐标。

## 目录

```
podcast-maker-book/
├── articles/               ← 47 篇正文源稿 + 8 篇部导读（唯一源，书稿即单篇）
├── book/                   ← 成书构件区（前置件 / 结语 / 七附录 / 构建管线 / 封面）
│   └── README.md           ← 构件与构建命令
├── wechat-publish/         ← 单篇对外发布的中间件（与入书无关，各自独立）
├── index.html              ← 落地页：在线阅读 / EPUB / PDF
└── 成册说明_我写故我播.md   ← 书是什么、八部是什么、怎么读
```

正文**不搬进** `book/`：单篇入书，`articles/` 是唯一源，`book/build/assemble.py` 按结构表拼接。

## 与《我思故我写》的关系

**平行同级**——不属于任何一册的附卷，也不存在主从。两册语料完全独立，关系是「方法论源头 → 第二应用现场」：前者给判断（圈画在哪、谁有权画），后者给证据（圈的实际坐标长什么样）。架构解析册与排版解析册是《我思故我写》的姊妹卷，本册不属其中。

## 构建

```bash
cd book && python build/build.py     # 全书 md + HTML + EPUB
python book/build/count_words.py     # 六口径字数（⑥ 为对外出版折算）
cd book/build/PDF && python make_pdf.py   # 印刷版 PDF（Playwright + 思源黑体）
```

依赖：Python 3.9+ 标准库即可出 md/HTML/EPUB（零第三方依赖）；PDF 另需 `playwright` / `pillow` / `pymupdf` 与思源黑体 OTF。产物落 `book/build/output/`——`book.html` / `book.epub` / `我写故我播全书.md` / `assets/` 随仓入版本（与《我思故我写》同规则，供在线阅读与直下），PDF 走 Release 附件。
