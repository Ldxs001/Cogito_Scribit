# 附录 A：术语表

> 全书核心术语一览。按主题分组，每条含：定义 + 出处（关联篇章）。

## 一、核心方法术语

| 术语 | 定义 | 出处 |
|------|------|------|
| **技能（Skill）** | 带元数据声明、可被标准校验的工具包——本书方法论的操作对象 | 第 I 部 |
| **智能体（Agent）** | 由链驱动架构编排的 LLM 执行系统 | 第 II 部 |
| **硬约束（Hard Constraint）** | 步骤原子化 + 硬中断 + 锁恢复——LLM 必须遵守、不可绕过的执行边界 | 01 |
| **构建时契约（Contract）** | 五层声明 + 接入校验——在构建阶段锁定技能的"正确形态" | 02 |
| **递归自举（Bootstrapping）** | 方法论约束自己——自我审计 + 自我约束 | 03 |
| **编排（Orchestration）** | Pipeline 编排：LLM 从"大脑"降级为"胶水" | 04 |
| **链驱动执行（Chain-Driven）** | 链是主体，LLM 只做两头——前处理与输出整理，中间确定性执行（每步输出受链定义校验） | 05 |
| **组合式检索（Compositional Retrieval）** | LLM 承担"查询策略规划者"——规划 = 语义标注元组，策略 = 算法穷举组合，组合多路检索 | 06 |
| **四条原则** | 如无必要勿增实体 / 如无规矩勿增操作 / 如无能力勿增限制 / 如无资源勿增承诺 | 07 |
| **有限决策范式（Limited Decision）** | LLM 只填空，不决策——决策权归链、架构与人 | 08 |
| **前置规范（Pre-emptive Specification）** | 前置规范 > 后置验证——把错误空间封堵在生成时刻 | 08a |
| **穷举（Enumeration）** | 用枚举保证稳定；穷举是 LLM 统计本质的定价 | 09 |
| **允许残余（Tolerated Residue）** | 接受可控噪声而非追求零污染——鲁棒性取舍 | 09a |

## 二、认知重估术语

| 术语 | 定义 | 出处 |
|------|------|------|
| **认知链（Cognitive Chain）** | 记住（人形图书馆）→ 说出（纸上谈兵）→ 合适引用（画龙点睛）→ 运用（落地生根） | 10 |
| **判断的让渡（Transfer of Judgment）** | AI 用暴力统计接管"记住→合适引用"——堆砌型知识贬值 | 10 |
| **翻译的打通（Unblocked Translation）** | AI 用巨量计算接管"表层→底层"——低代码复活 | 10 |
| **说的判断 / 做的判断** | 判断的两种形态：选知识（合适引用）/ 选路径（规划） | 10 |
| **运用（Application）** | 真实约束下的决策、执行、验证、负责——AI 够不到的最后一格 | 10 |
| **二元论断（Binary Judgment）** | 做工需要的"是/否"判断——取值有限，边界无限 | 10a |
| **划界（Demarcation）** | 判定实例属于哪一侧——二元论断的真正难点 | 10a |
| **逼近（Approximation）** | 用可枚举逼近不可穷尽（割圆术）——只在封闭系统收敛 | 10a |
| **失效即失控（Failure = Runaway）** | 逼近失效后误差正反馈放大，而不是优雅停止 | 10a |
| **画圈（Circling）** | 技术划"是"的边界 + 哲学划"应当"的边界——伦理牢笼的本质 | 10a |
| **划界权（Right of Demarcation）** | 谁有权画圈——只能由责任主体（人）垄断 | 10a |
| **责任闭环（Responsibility Loop）** | 试错 + 修复 + 有人负责——人类系统存活机制 | 10a |
| **画圈三问** | 谁画圈 / 圆画在哪 / 谁来守圆外 | 10a |

## 三、哲学概念（书中引用的外部概念）

| 术语 | 定义 | 出处（原文） |
|------|------|-------------|
| **休谟法则（Hume's Law）** | 从"是"推不出"应当"——事实与价值的鸿沟 | 休谟《人性论》 |
| **框架问题（Frame Problem）** | 开放世界中"相关事实"无法枚举 | 麦卡锡/海斯；丹尼特 |
| **索里特悖论（Sorites）** | 秃头悖论——二元判断的边界模糊 | 欧布利德斯 |
| **责任原理（Imperative of Responsibility）** | 行为后果须与人类永续存在相容；对恶的预测优先 | 约纳斯《责任原理》 |
| **人是目的（End in Itself）** | 把人性永远当作目的，绝不仅当作手段 | 康德《道德形而上学奠基》 |
| **知情同意（Informed Consent）** | 受试者自愿、知情、可退出 | 赫尔辛基宣言/纽伦堡法典 |
| **受试者优先（Subject Primacy）** | 受试者福祉优先于科学与社会利益 | 赫尔辛基宣言 |
| **独立伦理审查（IRB）** | 研究方案须经独立委员会事前审批 | 赫尔辛基宣言（1975 修订） |
| **善 / 正当 / 义务** | 元伦理学三大概念：价值 / 行为规范 / 必须做 | 规范伦理学 |
| **道德主体 / 道德客体** | 能负责者 / 应被善待者 | 元伦理学 |
