# 导读：方法论 ↔ 排版映射

> 母书《我思故我写》回答"为什么"——约束为什么是加法、穷举为什么是宿命、槽位为什么是减法。架构解析回答"怎么做"——这些原则如何落成七套真实运行的系统。本书回答"**怎么排**"——同一批内容，如何从源稿排成一本 35 章的书。
>
> 排版 01~05 五篇正文对应五层排版，每一层都回答一个排版问题；排版 06 是收束篇，不是第六层排版——它把五层当作一条完整任务执行流水线的标本，回答"为什么排版能无回头功地跑通"，并泛化到 skill 与 agent 执行任务。本导读给出映射表——读排版时可以回到母书对应篇目看原理，读母书时可以来这里看它落地成的版式。

## 一、五层排版路径

```flow
源稿排版（一）：表格/图/公式怎么写
    ↓ 单篇定稿（过四检）
元素排版（二）：入书后每个元素去留
    ↓ 进 book/
骨架排版（三）：四部、导读、章序怎么立
    ↓ 定结构
页面排版（四）：落到纸面一页页怎么切
    ↓ 出打印版
元数据排版（五）：字数、章数、版本号怎么对外
```

五层是流水线：写作形态 → 阅读形态 → 全书结构 → 纸面页面 → 对外数字。前一层定了，后一层才有输入。

流水线之上还有一层收束：排版 06 不做任何一层排版，它把上面五层当作一个完整任务来看——这三点机制（明确位置 / 对齐粒度 / 穷举正反例）内嵌在每一层里，五层才连成一条从头到尾无回头功的链；从排版泛化出去，skill、agent 乃至 LLM 执行任务跑的是同一条流程。它不是第六层排版，是对五层的综合。

| 排版篇 | 层 | 对应母书内容 | 落地的核心规则 |
|--------|-----|-------------|---------------|

## 三、怎么读

- **看版式**：读排版 01 + 04（源稿怎么写、纸面怎么排）
- **看成书流程**：按 01 → 05 顺序（五层流水线）
- **看完整任务执行**：按 01 → 06 顺序（五层 + 收束综合，06 回答五层为什么能连成一条完整流水线）
- **要落实规范**：每篇对应的规范本体在 `typesetting/STYLE_GUIDE.md`（源稿侧）与 `typesetting/STRUCTURE_GUIDE.md`（入书侧），正文六篇是这两份规范的展开叙述
