# Cogito 书族系转化入书规范（STRUCTURE GUIDE）

> 本文档固定**单篇定稿后入书**的全部标准：转化规则、配套同步、字数统计、版本号、构建管线与 PDF 打印版式。**族系唯一一份**，存于规范之家 `typesetting/`（与 STYLE_GUIDE.md、BOOK_GUIDE.md 同目录，分工见 BOOK_GUIDE.md 文件头层级表）。
> 与 STYLE_GUIDE.md 并列分工：STYLE_GUIDE 管**单篇写作**（版式/结构/描述方式/四检，写一篇时怎么写），本文档管**转化入书排版**（单篇定稿后怎么变成书——book/ 目录的成书全过程）。
> 基准范本：book 版 09e/09f（2026-08-25 09f 入书实战固化）；一~七章为母书/族系通用口径，**架构册（arch 卷）转化差异见第八章**。
> 单篇定稿（过四检）并需要入书（发布为 `book/part{X}/` 下的成书版本）时，按本规范执行。
> 标准一旦固定不再变动——改规范 = 改文档 + 改脚本 + 全量 rebuild。

---

> **章节导航**：一为转化规则（去留判据 + 10 系特例 + 工具收录）；二为配套同步清单（入书必做，缺一不可）；三为字数统计（六口径，⑥ 出版折算唯一对外）；四为版本号规范（三端一致校验）；五为构建管线（build.py 三步 + 拼接 + 渲染锚点）；六为 PDF 打印版式（make_pdf.py：页面字体 / 分页 / 封面 / 页码目录书签）；七为历史教训（防止复发）。

## 二、配套同步清单（转化后必做，缺一不可）

> **执行方式与 FAIL 定义（2026-09-04 定）**：转化完成后逐行过表，每行动作"做了且实证"才算勾。出现任一情形即 FAIL，禁止带 FAIL 进入构建——① 表中任一行未做（含行内"必改"数字：章数/篇数/统计值）；② 做了但未实证（如 build.py 输出章数与版权页不一致）；③ §四版本落点任一处不一致。四检管文章内容，本清单管入书操作——两者射程不重叠，都过才算完。

| 文件 | 动作 |
|---|---|
| `book/build/assemble.py` | STRUCTURE 列表注册新篇（`("part{X}/{文件名}", "第 {X} 部 · {篇号}")`），位置按部内顺序 |
| **book 版篇目引用表** | **从根目录同步「引用与出处说明」表（含修正内容），插在 `## 延伸阅读` 前**（09f 教训：book 版曾删引用表致 [n] 编号断链，2026-08-28 补回，见第七章） |

## 三、字数统计规范（全量维护点）

字数口径统一为 `count_words.py` ⑥出版折算（汉字 + 英文词 + 数字串）。**新增篇/章节数变化时，以下位置全部同步，缺一即 FAIL：**

| # | 位置 | 内容 | 更新时机 |
|---|---|---|---|
| 1 | `book/build/count_words.py` | 统计脚本（自动，无硬编码） | 每次 build 后运行取数 |
| 2 | `book/README.md` | `全书约 X 万字，N 章` | 章节数/正文变化 |
| 3 | 根目录 `README.md` | `约 X 万字，N 章` | 同上 |
| 4 | **`index.html`（在线阅读落地页）** | 四部结构卡片 `约 X 万字，N 章` | 同上（**历史上最易漏**，见第七章） |
| 5 | `book/frontmatter/00_版权页.md` | 版本记录尾部 `全书 N 章` | 同上 |


**字数六口径（count_words.py 算法定义，py 化规则文档化）**：

| 口径 | 算法 | 用途 |
|---|---|---|
| ① 总字符 | 全文 len()（含空白/md 语法） | 原始规模参考 |
| ② 去空白 | 去除全部空白字符后 len() | 紧凑规模 |
| ③ 纯汉字 | CJK 统一表意文字 `一-鿿` 计数 | 中文体量 |
| ④ 汉字+中文标点 | ③ + 全角标点区 `　-〿`/`＀-￯`/省略号破折号引号 | 接近阅读量 |
| ⑤ 去语法 | 去 `#*\|-`>[]()` md 符号后去空白 | 可见内容量 |
| **⑥ 出版折算** | **汉字数 + 英文单词数 + 连续数字串数**（中文出版常见折算）——**全书字数唯一对外口径** | README/版权页/index.html 落点 |

- ⑥ 为唯一对外口径，①~⑤ 仅内部参考；脚本读 `全书.md` 独立运行，每次 build 后取数回填（见第二章）

## 四、版本号规范（全量维护点）

**版本规则**：新增篇目/四部结构变化/章节数变化 → 次版本 +1（v1.2.0 → v1.3.0）；纯错字/格式修正 → 修订号 +1。**章数变化与版本号变化必须同时发生。**

| # | 位置 | 内容 | 更新时机 |
|---|---|---|---|
| 1 | `book/frontmatter/00_版权页.md` | 版本记录追加新条目（版本号 + 变更 + 章数） | 任何实质变更 |
| 2 | 根目录 `README.md` | 发行版 tag 描述 `book-vX.Y.Z` | 同上 |
| 3 | **`index.html`** | PDF 下载链接 `book-vX.Y.Z/book_vX.Y.Z.pdf` | 同上（**历史上最易漏**，见第七章） |
| 4 | GitHub/Gitee Release | 发布 tag `book-vX.Y.Z` + PDF 附件 | 发布时 |


**三端一致校验**：版权页记录版本号 == 根 README tag == index.html PDF 链接版本号，任一不一致即 FAIL。Release 发行：GitHub/Gitee 双平台 Release（tag `book-vX.Y.Z` + PDF 附件），PDF 附件随内容更新同步替换（同名覆盖：GitHub 删旧传新；Gitee 需 filename 参数指定 + 查列表删旧，同名上传是新增非覆盖）。

## 五、构建管线规范（py 化规则文档化）

> 构建脚本即规范：以下规则全部由脚本硬编码执行，此处文档化供人与 AI 对齐。改脚本 = 改规范 = 全量 rebuild。

### 5.1 构建主流程（build.py，三步）

```flow
book/ 各章节 md → [1/3] assemble 拼接 → 全书.md
    ↓
[2/3] md2html 渲染 → book.html（HTML 预览，在线阅读）
    ↓
[3/3] build_epub → book.epub（EPUB 发布）
```

- 入口：`cd book && python build/build.py`；输出目录 `book/build/output/`（三件产物）
- 新增篇目必须在 `assemble.py` 的 STRUCTURE 列表注册（`("part{X}/{文件名}", "第 {X} 部 · {篇号}")`），位置按部内顺序——未注册的篇目不进书

### 5.2 拼接规则（assemble.py）

| 规则 | 值 | 依据 |
|---|---|---|
| SPDX 剥离 | HTML 注释块整体去除，保留正文 | 成书无许可头（版权页统一声明） |
| 章间分隔 | 章与章之间直接空行衔接——**章间不注入分隔线** | h1 已强制每章新页；章间 hr 在"上章页满"时被推到下页首行且 h1 又新页 → hr 独占一整页（2026-08-28 教训，见第七章） |
| 首尾清理 | 每章 strip() 首尾空白 | 防拼接处双空行 |

### 5.3 渲染与锚点（md2html.py）

- 章内标题自动编号锚点：h1/h2/h3 顺序生成 `#hN` 锚点，目录两级（l1 = 章/部/附录，l2 = 小节）
- 渲染行为（表格 ref-table 识别 / flow / cols / chain / tree / math / text 分流）详见 STYLE_GUIDE 第一~三章——写作端怎么标，渲染端就怎么渲
- 字数脚本 `count_words.py` 独立运行（读 全书.md），六口径定义见第三章

### 5.4 产物清单

| 产物 | 路径 | 用途 |
|---|---|---|
| 全书.md | `book/build/output/全书.md` | 拼接源（字数统计输入） |
| book.html | `book/build/output/book.html` | 在线阅读 + PDF 打印版数据源 |
| book.epub | `book/build/output/book.epub` | EPUB 发布 |
| book_print.pdf | `book/build/PDF/book_print.pdf` | PDF 打印版（独立脚本，见第六章） |

## 六、PDF 打印版式规范（make_pdf.py，py 化规则文档化）

> 打印版从 `book.html` 出发二次加工：Playwright（Chromium）渲染 + PyMuPDF 后处理。以下规则全部脚本硬编码。

### 6.1 页面与字体

| 规则 | 值 |
|---|---|
| 纸张 / 边距 | A4，@page margin 18mm 16mm |
| 渲染视口 | 794×1123px（A4 @96dpi），与 @page 布局一致保证表格测量准确 |
| 正文字体 | SourceHanPrint（思源黑体 @font-face 三档 Regular/Medium/Bold，本地 OTF 加载，零字体分发） |
| 等宽字体 | SourceHanMono（思源等宽 @font-face 三档）；字体栈收敛为 `"SourceHanMono", Consolas, monospace`——**删 DejaVu Sans Mono 领头**（本地 TTF 与 @font-face CFF 混排触发子集化失效回退 NSimSun，见 STYLE_GUIDE 10.1） |
| 配色 | 打印强制 light——dark 媒体查询整体剥离 |
| 内容盒治理 | print 态 `*{box-sizing:border-box}` + body `max-width:665px; padding:0; margin:0`（去居中偏移）——**内容超 ICB（A4@96dpi ≈672px）即触发 Chromium 整本等比缩放**，全文字号偏离自然态（见 STYLE_GUIDE 11） |
| pre 长行 | pre-wrap + overflow-wrap:anywhere（raw 输出/长行不截断） |
| 表格宽度 | width:100% + table-layout:auto；td/th overflow-wrap:anywhere + word-break:break-word（表格横向溢出是整档缩放触发源之一，见 STYLE_GUIDE 11.1） |

### 6.2 分页规则（书籍标准）

| 元素 | 规则 | 依据 |
|---|---|---|
| h1 | break-before: page——每篇独立起页 | 书籍分篇惯例 |
| h2/h3/h4 | break-after: avoid——标题不落页末 | 标题孤行 |
| p | orphans: 2; widows: 2 | 段落防孤立行（3 太严会整段推页留大空白） |
| li | orphans: 1; widows: 1 | 单行 bullet 永远凑不满 2 行，widows 2 会永久推页留白 |
| hr / .flow-arrow | break-inside/after: avoid，**不加 break-before** | hr 前禁断页与 h2 后禁断页形成"保护链"，Chrome 把 hr+h2 整块推下页留半页空白（2026-08-28 教训，见第七章） |
| table | break-inside: auto，thead 跨页重复表头；tr 不拆 | 纵向结构允许内容单元间拆页，避免整块搬页留白 |
| blockquote / .flow-cols / .flow-layers | 不拆 | 横向并排/引用块完整性 |
| 超长元素 | JS 渲染前检测 offsetHeight > 单页可用高度（1123−2×68px），动态加 print-overflow 就地分页 | 避免"整块搬下页仍装不下再分页"导致第一页大空白 |
| 树形图 | .flow-treegroup scrollWidth 超预算（665−左偏移−14）则 zoom=预算/原始宽（clamp 0.5） | 消除软触发源后仅剩的硬溢出（等宽 nowrap 树行）；**须 emulate_media('print') 后测量**（见 STYLE_GUIDE 11.1 条 5-6） |

### 6.3 封面（make_cover_png）

- PIL 渲染 A4 **300dpi**（2480×3508）PNG 无损——300ppi 为印刷行业标准，600ppi 无感知增益
- 深蓝渐变 #12224A→#081630 + 金色标 #C9A45C；文字用思源黑体 OTF 直接画入图片（图片内文字，非字体分发）
- 封面印版本号、日期与字体许可声明（SIL OFL 1.1）

### 6.4 页码与目录（PyMuPDF 后处理）

- **页码**：封面 + 目录无页码；正文起始页（首个大字号"版权页"标题）= 页码 1；奇页右下 / 偶页左下（外侧），9pt 灰
- **目录**：点线引导 + 页码（版权页 = 1）+ 内部跳转链接 + PDF 书签大纲（l1 = 部/篇/附录，l2 = 小节，按缩进 x 判层级）
- 正文标题匹配阈值 **>=15**（自然字号标定：正文 12pt 排除、h2 16.8 / h1 20.4 命中；缩放态旧值 >=12 随自然态重校准，见 STYLE_GUIDE 11.2）
- 目录行**跨行合并**（同页按 y 排序，间距 <23pt 的相邻行视为同一跨行条目；超长标题折行续行碎片曾误配"结语"h1 污染顺序锚致 10a/10b 24 条漏配）+ **顺序锚定 miss 全局回退**（见 STYLE_GUIDE 11.1 条 7）；纯数字页码列行剔除
- **目录页码列铁律**（页码不压 .toc 边框、不与虚线重叠）：三项数值同步收紧——页码右对齐基线 **x=538**（距 .toc 装饰右边框 x=543.4 留 5.4pt 安全间距，1/2/3 位数字右缘统一入框）、虚线终点 ≤ **x=521**（距三位数页码左缘 ≥3pt）、link_rect 右缘 ≤ **x=543**（贴合边框不溢出）。三项耦合单改一项会引入新错位。详见 STYLE_GUIDE 11.4
- 依据：Chromium 不支持 CSS target-counter() 且打印不生成内部链接/书签，全部后处理补齐

### 6.5 产物链与依赖

```flow
cover.png（PIL 300dpi） + 正文 body.pdf（Playwright）
    ↓
PyMuPDF 合并（封面页前置，garbage=3 + deflate 压缩）
    ↓
页码插入 → 目录点线/链接/书签 → book_print.pdf
```

- 前置：pip install playwright pillow pymupdf + python -m playwright install chromium + 本目录思源黑体 OTF 三档
- 中间产物（book_print.tmp.html / body.pdf）用后即清
- 发行：PDF 不进仓（.gitignore），走 GitHub/Gitee Release 附件（tag book-vX.Y.Z）
