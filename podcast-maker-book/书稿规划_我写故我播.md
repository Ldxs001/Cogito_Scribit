# 书稿规划：《我写故我播——播客智能体技术复盘》

> **定位**：把 `podcast-maker` 项目的更新日志（CHANGELOG）当成一座技术文章矿，按"问题"而非"版本号"拆成 36 篇中篇技术复盘，先发首季 12 篇、看反馈再扩。本书是这座矿的**成书规划与写作标准**，不是更新日志本身。
> **源锚（当下快照）**：`CHANGELOG_快照_2026-10-08.md`（与本规划同目录）。项目仍在更新，本规划只覆盖快照日之前已落地的故障与修复；快照日之后新增内容不进本书，需另起补篇或新版。
> **书名已定**：`《我写故我播》`，与母书《我思故我写》同族系（我思→我写→我播）。成书装配时版权页 / 导读 / 封面统一用此名，无备选。
> **规范之家**：单篇怎么写、四检、成书管线一律以 `Cogito_Scribit/typesetting/` 三份规范为准（STYLE_GUIDE 单篇 / STRUCTURE_GUIDE 入书 / BOOK_GUIDE 书籍结构）。本文件是**项目级规划**，不复制规范条文，只引用与落地适配。

---

## 一、为什么是书，不是公众号合集

CHANGELOG 的天然骨架就是技术文章的骨架：**现象 → 根因 → 修法 → 验证**。它不空泛——有真实故障、实测数字、测试钉子、架构取舍。逐条拆开可独立成篇，且篇篇带硬货（28～34 dB、13.6 LU、83.78 dB、0.65 MB/s vs 6.3 MB/s、17.8 min→4.8 min）。

成书（而非公众号合集）的理由：
- **结构可复用**：七部、三十七篇共用一套固定七段结构，读者形成稳定预期；
- **验证可沉淀**：每篇过四检（真实性 / 底层逻辑 / 空推论 / 循环论证），引用表锚到 CHANGELOG 条目与代码行，可回溯；
- **版本可对外**：`podcast-vX.Y.Z` 三端一致（版权页 == README == index.html == PDF 封面），双平台 Release；
- **黑话可收束**：`fail-closed` / 幂等 / 门禁 / 清场 / 账本 / 同源律 / 双零 全部进附录术语表，正文首现四维展开。

### 3.2 黑话首现四维展开（09f 同构，至少解释 + 举例）

正文首现以下术语必须先用一句话定义，再进细节；统一收尾进附录术语表：

| 术语 | 一句话定义（首现写这句） |
|---|---|
| fail-closed | 出错时默认失败、不静默继续，靠报错而非假装成功暴露问题 |
| 幂等 | 同一操作重复执行结果一致，可安全重试而不产生副作用 |
| 门禁 | 提交/发布前的自动检查，不过即阻断（如引语硬校验 fail 级） |
| 清场 | 任务结束清理临时文件/进程的收尾动作，做错会误删成品 |
| 账本 | 进度/预算的确定性记录（如进度条五段预算），不靠猜 |
| 同源律 | 多份产物由同一数据源一次生成、不互相反解，避免漂移 |
| 双零 | 两段 stdout 纪律——结果通道只留一行 JSON，其余归 stderr |

### 3.4 描述方式白黑名单（锚定 STYLE_GUIDE §六，适配本项目）

| 描述方式 | 白名单 ✅ | 黑名单 ❌ |
|---|---|---|
| 引用来源 | 正文只 `[n]` 编号；编号指向本文引用表 | 来源描述文字替代编号；版本号/文件路径/commit 进正文 |
| 引用表出处 | `podcast-maker · CHANGELOG.md · vX.Y.Z · 条目` + `path/file.py:Lnn` + `（项目实证）` | 正文任意位置出现核验标注 |
| 数字 | 实测数字 + 来源条目 + 测量条件 | 无条件裸数字（"成功率 90%"不给出处） |
| 认知分级 | 正文括号标 `（机制性推断）` / `（经验刻画）` | 无标注裸断言（级别上浮 = 最严重违规） |

| 收束句 | 重述已论证论点 | 引入新论点 / 新意象 |

### 3.5 四级命题标注（STYLE_GUIDE §7.1，本项目映射）

| 级别 | 本项目标注 | 证据义务 |
|---|---|---|
| L1 文献结论 | 挂 `[n]` | 出处列给 CHANGELOG 条目 / 代码行 / 实测条件 |
| L2 本文推导 | 显式"本文推导" | 推导链在文内可查 |
| L3 机制性推断 | 显式"机制性推断"并标依据 | 写明基于哪条 L1/L2 |
| L4 经验刻画 | 显式"经验刻画" | 挂具体项目记录（版本条目） |

**核心禁令**：禁止级别上浮——把 L3/L4 写成 L1（"我认为"伪装成"日志表明"）是最严重论证违规。

### 3.6 文风（结论先行，结构固定）

1. **结论先行**：摘要给核心矛盾，每章首段给本章结论。
2. **标题 = 现象 + 技术点**：如"字幕断词：一个 return hi 兜底硬切在词中间"，不写"字幕处理优化"。
3. **一篇一矛盾**：不把 v2.0.0 全塞一篇；BGM 生成至少拆搭建/清场误杀/徽标探测/ stdout 污染 4 篇。
4. **按问题写，不按版本号写**：`v2.0.0` 不是选题，"成品被自己的清场删掉"才是。
5. **禁用第二人称"你"**（书族系全册样式统一铁律）。
6. **统一收束口号**：`Cogito, Scribo. 我写，故我播。`

## 四、单篇四检与校正（STYLE_GUIDE §八，PASS/FAIL 二元）

写完必检，顺序固定：**真实 → 逻辑 → 空转 → 循环**。任一 FAIL → 回修 → 四项全量重检。结果写入脚注（见 3.1 模板末行）。

| 检测 | 本项目判据（适配） |
|---|---|
| 一、真实性 | 每条 `[n]` 可回溯到源条目 / 代码 `path:Lnn` / 实测条件；数字带条件；正文无黑名单命中。**出处署名一律写 `podcast-maker · CHANGELOG.md · vX.Y.Z`（真实项目源），内部快照文件名禁止出现在任何稿面**（快照仅作写作时核对底稿） |
| 二、底层逻辑 | 命题改写"在 C 下 X 成立"，两两比对：交域互斥 → FAIL；域切分切开 → 合法 |
| 三、空推论 | 每个论证性命题挂 L1~L4 之一；显式猜想合法，伪装结论不合法 |
| 四、循环论证 | 文内命题互撑闭环且环上全部无环外依托（CHANGELOG/代码/实测）即 FAIL；良性引用链 = 环外有锚 |

**引用表断链红线**（STRUCTURE_GUIDE §七）：书内任一 `[n]` 在本篇引用表查不到对应行即 FAIL。本书每篇引用表即"CHANGELOG 条目 + 代码行"正表，必随篇同步。

### 5.3 版本号与三端一致

- 版本规则：新增篇目 / 部结构变化 / 章数变化 → 次版本 +1（`podcast-v1.0.0` 起）；纯错字 → 修订号 +1。**章数变化与版本号变化必须同时发生**。
- 三端一致：版权页版本 == 根 README tag == index.html PDF 链接 == PDF 封面版本字，任一不一致即 FAIL。
- 发行：GitHub/Gitee 双平台 Release（tag `podcast-vX.Y.Z` + 附件 `book_podcast-vX.Y.Z.{pdf,html,epub}`）；PDF/字体不进仓。

### 14.1 声门三件套与傅里叶域分段（第 9 维，#13/#36 取材）

**原理（源-滤波模型，Fant 1960）**：`s=e*h`（时域卷积）→ `S(f)=E(f)·H(f)`（频域相乘）→ `log|S|=log|E|+log|H|`。`log|H|`=慢变谱包络=声道形状=音色；`log|E|`=快变谐波梳=基频=音高。取对数变相乘为相加，再对 log 谱低通 liftering（倒谱）分离两者：低 quefrency=声道包络（几乎不随音高变），高 quefrency=基频周期（quefrency 上 1/F0 处峰）。同态处理/倒谱（Bogert, Healy & Tukey 1963；Oppenheim 同态滤波）；工业版 MFCC=mel 滤波→log→DCT→保留低阶=谱包络=音色。（L1 文献：`2026-10-01-14-52-24/_ab_timbre_dims.md`）

**第 9 维算法（真实仓 `podcast_maker/seg_incursion.py`，v2.3.0）**：

| # | 量 | 算法 | 对 F0 免疫机制 |
|---|---|---|---|
| ① 倒谱谱包络 `D_cep` | 帧平均幅度谱→`log10`→`irfft` 取倒谱→只留 quefrency<2ms→`rfft` 回谱包络→13 个对数频点采样→逐点减自身均值（去增益与倾斜，只留共振峰形状）→与角色池逐系数 σ 归一求 RMS | 1/F0 在 70~500Hz 对应 2~14ms，全被 lifter 切门外；形状量不含 F0 |
| ② 同句自比 `D_rel` | 被点名段包络 vs 同一句其它段中位包络（池 σ 归一） | 同上；另消句级通道/语速差异 |
| ③ 声门三件套 `D_glot` | 逐有声帧 CPP+HNR+H1*–H2*→段内中位→角色池 μ/σ 归一 | 量的是声源，不是声道也不是音高 |

**三个量公式口径**：`CPP`=倒谱峰相对回归线高度（Hillenbrand 1994）；`HNR`=归一化自相关峰 `10·log10(r/(1−r))`（de Krom 1993 / Praat 口径）；`H1*–H2*`=F0、2F0 处幅度差再减掉倒谱包络在两点的落差（去声道影响）。
**真实签名（两个独立来源件同套）**：CPP 0.56/0.62（池 0.28）、HNR 9.08/8.91（池 5.17）、H1*–H2* −4.32/−8.58（池 +1.06）→ 真混入；同人喊高三个量全贴池均值（抬音高不改声门开商）。（L1 文献：`_ab_timbre9_findings.md` §2/§4）
**分离度**：`D_cep` AUC 0.810、`D_rel` 0.857、`D_glot` 0.762；可行口径 `抑制 ⟺ D_cep<池80分位(1.47) 且 D_glot<池70分位(0.94)`，池内报警 42→18 句(−57%)。
**顺带两件（v2.3.0 同记）**：第 8 维线定错（固定线 3.2≈中位数→报警 53%；改池 90 分位 z=5.73/4.27→报警 7%）；倍频嫌疑证伪（改用谐波梳命中率，`hit(f0/2)` 中位 0.50，≥0.83 段 0/74→真基频非倍频）。

**基嗓 base_ref 与 ICL（v2.2.0 / v2.5.0 / v2.6.0）**：句首约 0.9s 说话人条件未充分调制（多模态吸引子），同句只换种子句首中位 F0 在 143~310Hz 摆动 → 有效手段改条件而非采样旋钮（`non_streaming_mode` 45%→70% 恶化、`top_p`/`instruct` 动不了句首，v2.2.0 实测否决）。段首预热（ICL 前缀在档案后再接同角色真实语音）实测女声区 6/15→1/15；`tts_service/make_base_ref.py` 以 Base 克隆自造前缀可完全替代当期成品前缀；双案造嗓草稿目录在 `podcast_maker/web_ui.py`（~1422，`_draftA/_draftB`）。阈值出处：段长门 0.20s、段级统计量 85 分位、谐波和上限 6 次/500Hz、次谐波守卫门 0.80（v2.3.0 `_ab_landing_plan_v2.md` §4）。
**v2.6.0 ref_base 版本账本（#37 取材）**：`ref_base_<sign>.wav`/`icl_<sign>.wav`，sign=原生 ref 的 sha256 前 8 位（文件名即映射）；角色账本 `音色/<角色>/base_refs.json`（`entries[sign]`+`active`，同一原生 ref 永远只克隆一次）；换嗓三处接线 adopt/adopt_official/inherit 接 `ensure_base_ref()`；`_ref_pair()` 缺件 fail-closed 硬报错绝不静默退回 ref.wav；体检锚从 `ref.wav` 改为当期同源 `ref_base_<sign>`。实测 `cos(ref_base_<sign>, 原生 ref)`=A 0.994/B 0.974，1519 测试通过。
