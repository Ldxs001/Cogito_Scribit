## 二、每篇一句话命题

| 篇 | 命题 |
|----|------|
| 01 硬约束架构 | 多步骤确定性流程中，LLM 的"自觉"是负资产 |
| 02 构建时契约 | 用五层声明锁定技能的"正确形态" |
| 03 递归自举 | 方法论不约束自己，就没有约束任何东西的资格 |
| 04 技能流水线编排 | LLM 从"大脑"降级为"胶水" |
| 05 链驱动执行 | 链是主体，LLM 是执行器 |
| 06 领域智能体 | LLM 承担"查询策略规划者"，组合式检索 |
| 07 四条原则元逻辑 | 架构的减法与约束的加法 |
| 08 有限决策范式 | LLM 只填空，不决策（三体印证） |
| 08a 操作层 | 前置规范 > 后置验证；最小尝试次数的分工与监督 |
| 09 边界篇 | 穷举的宿命——稳定与随机的悖论 |
| 09a 检索层注脚 | 探测的边界——RAG 检索鲁棒性的取舍 |
| 10 认知重估 | 判断的让渡与翻译的打通——两种力气活的终结 |
| 10a 伦理牢笼 | 割圆术的边界——伦理牢笼与 AI 的宿命 |

## 四、全书一句话

> **人用判断划定 AI 的边界：圈内让 AI 做工，圈外由人负责。** ——从第 I 部"约束 LLM 的输出"，到第 IV 部"约束 LLM 的能力"，本质是同一件事：划界权在人。
