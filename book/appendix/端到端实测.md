> **测试性质**：单次 e2e 演示，**有限测试**——一次采样，不是统计基准。文中所有指标描述的是本次运行的观测，不构成对模型或方式的稳定性结论。
>
> **成绩解读**：本附录各方式成绩优秀，**存在考题偏颇因素**——考题按"不守规矩的模型会翻车"设计（演示默认考题），对对齐良好的模型偏简单；且部分高指标由 **PY 门禁兜底贡献**（如发散纠偏的"达标"由代码删词保证、检出上报的"检出率"由正则保证），非模型能力本身。**成绩不作为模型或方式的普适结论。**
>
> **运行环境**：LM Studio 本地推理，模型 **Qwen3.5-35B-A3B**（GGUF q4_K_M 权重量化，KV cache **Q8_0 量化**）。
>
> **重要说明**：本附录所有指标的**计算与解读/判定**由测试工具内置机器解读自动生成，**未经人工审查**；token 计数为工具内置**粗略估算**（字符数 × 1.5，中英文统一系数，`e2e_demo._est_tokens`，注释"中文约 1.5 token/字，取 1.5 偏保守"），非模型后端精确计数。
>
> **执行结构**：每个方式统一按「输入 / 设置 / 输出 / **LLM 与 PY 分工** / 指标 / 机器解读」呈现。**生成内容全部由 LLM 完成，校验判定、确定性后处理、重试控制、指标计算全部由 Python 门禁完成**——"达标"与否的裁判是代码，不是模型自评。
