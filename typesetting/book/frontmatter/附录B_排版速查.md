# 附录 B 排版速查

> 五层排版的一页速查。完整规则见正文五篇与 `typesetting/STYLE_GUIDE.md`、`typesetting/STRUCTURE_GUIDE.md`。

## 一、源稿渲染标注速查（排版 01）

| 标注 | 渲染 | 何时用 |
|------|------|--------|
| `flow` | 流程卡片流 | 线性流程链、决策树、组合图 |
| `cols` | 并排多列 | 多列对比 |
| `chain` | 横向链 + 注释 | 主链 + 层级注释 |
| `tree` | 等宽代码框 | 文件树/结构树（无箭头） |
| `text` | 纯文本 pre | 模板/提示词/raw 输出（含 → 必标） |
| `math` | 居中公式块 | 独立公式 |
| `python`/`json` 等 | 代码 pre | 真实代码 |

- 行内公式 `$...$`；单元格内禁 `\|` 转义（用全角 `｜`）；缩进 2 空格 = 1 级

## 二、元素去留判据速查（排版 02）

| 元素 | 成书处理 |
|------|---------|
| SPDX 许可头 / 摘要+更新行 / 篇尾脚注 / 无编号非标章节 | 去除 |
| 正文（含 [n] 编号、认知分级标注）/ 引用表 / 延伸阅读 | 保留（延伸阅读条目加"第 X 部 ·"前缀） |
| 10 系收束签名（Cogito, Scribo.） | 保留（系列身份非痕迹） |
| 尾部顺序 | 正文 → 引用表 → 延伸阅读 → 结束 |

## 三、页面分页规则速查（排版 04）

| 元素 | 规则 |
|------|------|
| h1 | 每篇独立起页（break-before: page） |
| h2/h3/h4 | 标题不落页末（break-after: avoid） |
| 段落 | orphans/widows 2（防孤立行，3 太严） |
| 列表项 | orphans/widows 1（单行 bullet 不推页） |
| 表格 | 允许跨页、表头重复；tr 不拆 |
| 横向并排/引用块 | 不拆 |
| 超长元素 | print-overflow 就地分页 |
| 字体 | 思源黑体（OFL 1.1），禁用闭源字体——长尾收益 |

## 四、数字口径速查（排版 05）

| 项 | 规则 |
|------|------|
| 字数 | ⑥ 出版折算 = 汉字 + 英文单词 + 数字串（唯一对外口径） |
| 章数 | 35 = 正文 21 + 导读 4 + 结语 1 + 前置页 3 + 附录 6 |
| 版本 | 结构变化 → 次版本 +1；错字/格式 → 修订号 +1；章数变则版本必变 |
| 三端 | 版权页 = 根 README tag = 落地页 PDF 链接版本号 |
