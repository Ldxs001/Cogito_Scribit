# 附录 B 排版速查

> 五层排版 + 规范/管线 + 收束篇的一页速查。完整规则见正文八篇与规范之家 `typesetting/`（STYLE_GUIDE / STRUCTURE_GUIDE / BOOK_GUIDE）。

## 一、源稿渲染标注速查（排版 01）

| 标注 | 渲染 | 何时用 |
|------|------|--------|
| `flow` | 流程卡片流 | 线性流程链、决策树、组合图 |
| `cols` | 并排多列 | 多列对比 |
| `chain` | 横向链 + 注释 | 主链 + 层级注释 |
| `tree` | 等宽代码框 | 文件树/结构树（无箭头） |
| `text` | 纯文本 pre | 模板/提示词/raw 输出（含 → 必标） |
| `math` | 居中公式块 | 独立公式 |
| `python`/`json` 等 | 代码 pre | 真实代码 |

- 行内公式 `$...$`；单元格内 `\|`（GFM 转义，2026-09-02 引擎支持，含行内代码内）与全角 `｜` 均合法——旧"禁 `\|`"禁令随引擎升级解除（拆表事故时代 2026-08-28 旧引擎行为）；缩进 2 空格 = 1 级

## 二、元素去留判据速查（排版 02）

| 元素 | 成书处理 |
|------|---------|
| SPDX 许可头 / 摘要+更新行 / 篇尾脚注 / 无编号非标章节 | 去除 |
| 正文（含 [n] 编号、认知分级标注）/ 引用表 / 延伸阅读 | 保留（延伸阅读条目加"第 X 部 ·"前缀） |
| 10 系收束签名（Cogito, Scribo.） | 保留（系列身份非痕迹） |
| 尾部顺序 | 正文 → 引用表 → 延伸阅读 → 结束 |

## 三、页面分页规则速查（排版 04）

| 元素 | 规则 |
|------|------|
| h1 | 每篇独立起页（break-before: page） |
| h2/h3/h4 | 标题不落页末（break-after: avoid） |
| 段落 | orphans/widows 2（防孤立行，3 太严） |
| 列表项 | orphans/widows 1（单行 bullet 不推页） |
| 表格 | 允许跨页、表头重复；tr 不拆 |
| 横向并排/引用块 | 不拆 |
| 超长元素 | print-overflow 就地分页 |
| 字体 | 双族注册开源字体（SourceHanPrint / SourceHanMono，OFL 1.1 + SourceSans3 Latin 兜底），禁用本地字体领头与闭源字体——长尾收益 + 防子集化回退 |
| 内容盒 | print 态 `*{box-sizing:border-box}` + body `max-width:665px` 左对齐 margin:0——内容超 ICB（≈672px）触发 Chromium 整本等比压缩 |
| pre / 表格 / 流程标签 | print 态软断行（pre-wrap / width:100% / white-space:normal），树形图等宽树行按需 zoom（预算 665） |
| 目录标题匹配 | 字号阈值 ≥15（自然态：正文 12pt 排除、h2 16.8 / h1 20.4 命中）；跨行条目 y 间距 <23pt 合并 |
| 目录页码列 | 页码右对齐基线 x=538 / 虚线终点 ≤521 / 链接区右缘 ≤543——三项耦合，页码 100% 入 .toc 边框（543.4） |

## 四、数字口径速查（排版 05）

| 项 | 规则 |
|------|------|
| 字数 | ⑥ 出版折算 = 汉字 + 英文单词 + 数字串（唯一对外口径） |
| 章数 | 35 = 正文 21 + 导读 4 + 结语 1 + 前置页 3 + 附录 6 |
| 版本 | 结构变化 → 次版本 +1；错字/格式 → 修订号 +1；章数变则版本必变 |
| 三端 | 版权页 = 根 README tag = 落地页 PDF 链接版本号 |

## 五、规范与管线速查（排版 06/07）

| 项 | 规则 |
|------|------|
| 三规范 | STYLE_GUIDE（单篇）/ STRUCTURE_GUIDE（转化）/ BOOK_GUIDE（书籍结构）——流水线顺序即分工顺序 |
| 规范之家 | 全部规范唯一存放 typesetting/，各仓不持规范文件；文件名英文大写 X_GUIDE；旧文件归档优于删除 |
| 定义点 | 每条规则只有一个定义点；冲突裁决：书籍结构 ＞ 转化 ＞ 单篇 |
| 治理链 | 改规范 = 改文档 + 改脚本 + 全量 rebuild；产物实证扫描后才算改对 |
| 管线 | assemble（清洗+注册装配）→ md2html（锚点渲染）→ build_epub；make_pdf（封面/页码/目录/书签后处理）；count_words（六口径） |
| 清洗判据 | 剥什么由内容特征决定（含日期戳才剥摘要），不由位置决定；未注册不进书 |

## 六、任务执行三机制速查（排版 08 · 收束篇）

| 机制 | 保证什么 | 排版里的落地形态 | 缺它时的症状 |
|------|---------|-----------------|-------------|
| 明确位置 | 做功有效，无回头功 | 处理只挂一个环节（如拆表只在 md2html 解析层）；门禁失败只回退到对应环节 | 反复回头、丢进度、不知道执行到哪 |
| 对齐粒度 | 复用可能、解读成本低 | 相似子任务收口到同一处理点（如拆分规则全在 `_split_row`）；同类结构共用同一模板 | 随机误差、产物不可复用、每次重新解读 |
| 穷举正反例 | 纠偏一次到位 | 事故登记册（规范条文 + 渲染器判定）；单测固化反例；对照实验排查反例 | 重试靠运气、纠偏不完整、同错重犯 |
