# 成书排版（四）：页面排版——从屏幕到纸面

> 屏幕是流，纸面是页。HTML 是连续滚动的，打印版必须一页一页切——切页规则就是页面排版。本文展开打印版页面排版的全部规则与逻辑：分页逻辑（每篇独立起页、标题不落页末、防孤立行）、空白治理（两次真实的分页事故与修正）、书的物理规范（A4、字体、封面、页码、目录）。边界声明：本文覆盖打印版页面级排版；元数据级（字数/版本号）由本系列第五篇承担 [1]。

## 一、引子：屏幕是流，纸面是页

在线阅读的 HTML 是连续的——读者滚轮一滚，28 万字符从头到尾不断流。打印版做不到：A4 纸有边界，内容必须一页一页切下来。切在哪、怎么切，就是页面排版的全部问题。

切页规则藏在打印版生成脚本的打印 CSS 里，每一条都是真实排版的取舍——而且其中两条是事故换来的 [1][2]。打印版不是 HTML 的缩小，是同一个内容在"页"这个容器里的重新排版。

## 二、分页逻辑：四条规则，四条理由

**规则一：每篇独立起页（h1 强制新页）。** 打印 CSS 里 `h1 { break-before: page }`——每一个一级标题（版权页、序言、每篇、结语、每个附录）强制从新页开始 [1]。逻辑：书的章节天然以篇为单元，一篇从新页起，读者翻开任何一页都能判断"我正读的是哪一篇"，也方便折页标记。这是书籍分篇的惯例，不是偏好。

**规则二：标题不落页末（h2/h3/h4 禁止断页在标题后）。** `break-after: avoid`——小节标题必须与后续内容同页 [1]。逻辑：页末孤零零一个标题，翻页后内容在下一页，读者的视线断了。标题是导航标记，标记必须指向内容，不能指向空白。

**规则三：防孤立行——段落与列表分别取值。** 段落 `orphans: 2; widows: 2`（页首页底最少 2 行）；列表项 `orphans: 1; widows: 1` [1]。这个取值是实测出来的：段落设 3 太严，触发整段推页造成大空白；列表项大多是单行 bullet，若也设 2，单行条目（1 行 < 2）永远被推下页，每页底部留一条白。逻辑：**防孤立行的目的是阅读连续性，但取值必须按元素形态分别定**——段落是长文本，列表是短条目，一刀切反而制造新空白。

**规则四：纵向结构允许拆页，横向结构不拆。** 表格允许跨页（跨页重复表头）、tr 不拆；引用块、并排多列不拆 [1]。逻辑：表格是纵向延伸的，跨页是它的自然形态，表头重复保证跨页后读者仍知道每列是什么；横向并排结构一旦拆开，左右对照关系就断了。拆与不拆，由结构的方向性决定。

**规则五：长行不截断——代码块强制换行。** 打印 CSS 里 `pre { white-space: pre-wrap; overflow-wrap: anywhere }`——代码块的长行保留原换行、允许软换行、超长词兜底断开 [1]。逻辑：书里大量 raw 输出（测试实录、日志）是超宽单行，屏幕上有横向滚动条，纸面上没有——如果不强制换行，超宽行会被直接裁掉，内容丢失。**排版不能让内容消失**，这条规则保证纸面承载的内容与屏幕一致。

## 三、空白治理：两次事故换来的两条规则

页面排版最大的敌人不是内容太多，是**空白太多**——内容被"保护性"地推到下一页，留下一整页或半页空白。两次真实事故：

**事故一：保护链造成的半页空白。** 打印 CSS 曾对分隔线（hr）加了"禁止断页"的规则，本意是分隔线不独占页。但分隔线的断页保护与标题的断页保护连成一条"保护链"：分隔线不能断、它后面的标题也不能断，两者作为一个整体被浏览器推到下一页——上一页留下半页空白 [2]。修正：hr 只保留"后部禁断页"（`break-after: avoid`），去掉"前部禁断页"——分隔线可以留在页尾，不再触发整块搬运。

**事故二：章间分隔线独占一整页。** 拼接全书时曾在章与章之间注入分隔线。某章内容正好顶满一页时，分隔线无处安放被推到下一页首行，而下一章标题又要新起一页——分隔线独自占了一整页 [2]。修正：章与章之间不再注入分隔线——章节分隔由标题层级承担，这印证了元素级排版里"层级承担分隔"的逻辑：**分隔是结构问题，不是装饰问题，装饰性的横线在页面上会变成空白**。

**治理的最后一环是超长元素就地分页。** 单页装不下的超长表格/引用块，渲染前先检测高度，超出单页可用高度（A4 高 1123px − 上下边距 136px）就标记为"就地分页"——在内容单元之间拆，而不是整块搬下页再拆，避免第一页先留一大块空白 [1]。逻辑：**超长元素的正确排法是在它内部切，不是把它整体搬走**。

## 四、书的物理规范：纸、字、封、码

页面排版除了切页，还有四个物理层。

**纸：A4，边距 18mm 16mm。** 打印版渲染视口取 794×1123px（A4 @96dpi），与打印布局一致，保证页面元素测量准确 [1]。边距上下 18mm、左右 16mm——正文区的宽高在渲染前是确定的，超长元素判定（见第三章）用的"单页可用高度"就是按这个边距算的：1123px 减去上下边距 136px。**纸面尺寸是页面排版的基准坐标系**，所有"放不放得下"的判断都建立在它之上。

**字：思源黑体，零字体分发。** 正文字体用思源黑体（Regular/Medium/Bold 三档），以本地 OTF 加载、按字重映射——标题用 Medium/Bold、正文用 Regular，等宽场景回退 DejaVu Sans Mono [1]。封面文字用字体直接画入图片。逻辑：**打印版不能依赖读者电脑里有这套字体，也不能把字体文件随 PDF 分发**——零分发、零授权争议，是打印版的分发前提 [1][3]。字体名在打印版里整体替换（从屏显字体栈换成思源黑体栈），保证纸面与屏幕的观感一致，不是让两种介质各长各的。

**为什么是思源黑体而不是系统字体——长尾收益原理。** 用微软雅黑渲染 PDF 大概率不侵权，但"大概率"不是选字体的标准。风险是期望值里的尾部：闭源字体随系统授权，不授予单独分发与商业嵌入，PDF 分发后字体是否随文档传播、边界是模糊的——概率低，但一旦触发（厂商追索、平台下架），整本书的分发停摆，损失远超省下的功夫。思源黑体是 SIL OFL 1.1 开源许可：自由使用、嵌入、分发，把概率归零，换来"永远不必处理这类问题"的确定性。**确定性的价值就是长尾收益——用零授权成本，买断一类风险。** 封面印上字体许可声明（SIL OFL 1.1），许可透明写在书面上，任何渠道分发都无后顾之忧 [1][3]。

**封：A4 300dpi 位图。** 封面用渲染生成 300dpi（2480×3508）PNG——300ppi 是印刷行业标准，600ppi 在阅读距离无感知增益 [3]。封面是位图、正文是矢量，两者物理分离、合并不互相污染 [1]。封面印版本号、日期与字体许可声明——书的元数据在封面上的落点，见本系列第五篇。

**码：页码与目录。** 页码规则：封面与目录页无页码，正文起始页（版权页）= 页码 1，奇页右下、偶页左下（外侧）[4]。目录页用点线引导 + 页码 + 内部链接 + PDF 书签——打印渲染器不生成内部链接与书签，全部由后处理补齐 [4]。目录分两级：一级是部/篇/附录（顶格），二级是篇内小节（缩进），按缩进坐标判级 [4]。逻辑：**页码是读者在纸面上定位的坐标，目录是纸面上的导航**——两者都是页面的功能性排版，不是装饰。点线把"标题 → 页码"连成一条可见的追踪路径，书签让电子阅读者能点击跳转——纸面与数字两套导航并存，各服务一种读法。

## 五、结语：切页规则就是页面排版

页面排版解决一件事：连续的内容如何变成离散的页，且不制造空白、不折断视线。四条分页规则（独立起页、标题随文、防孤立行、按方向拆页）、两次事故换来的空白治理、四个物理层（纸、字、封、码），构成了打印版的完整页面排版。

到这一步，一章的形态定了（元素级）、一章的位置定了（骨架级）、一页的切法定了（页面级）——打印版从连续流变成离散页，页页有边界、处处不落空。还剩最后一层：书对外的数字——字数、章数、版本号怎么在书和落地页上排布，下一篇展开。
