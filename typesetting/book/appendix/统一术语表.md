# 附录 A 统一术语表

> 本册术语与母书、架构解析共用同一套词汇；此处收录排版侧的核心术语，定义与出处 = 母书相关篇目或本册正文篇。

| 术语 | 定义 | 出处 |
|------|------|------|
| 源稿 | 仓库根目录的单篇（`NN_xxx.md`），写作形态，含摘要/更新行/脚注 | 排版 01 |
| 成书版 | book/ 目录的章节，阅读形态，去写作痕迹 | 排版 02 |
| 版式 | 内容在介质（屏/纸）上的呈现规则——列宽、层级、分页、落点 | 排版 01 |
| 版心 | 打印版正文区：A4 减 18mm 上下、16mm 左右边距 | 排版 04 |
| 分页 | 连续内容切成离散页的过程与规则 | 排版 04 |
| 断页 | 分页点在标题后/孤立行等破坏阅读的位置 | 排版 04 |
| 孤立行 | 页首/页底单独一行（orphans/widows 控制的孤行） | 排版 04 |
| 标注分流 | 代码块语言标注决定渲染形态（flow/cols/chain/tree/text/math） | 排版 01 |
| 层级即分隔 | 章节分隔由标题层级承担，不靠装饰横线 | 排版 02 |
| 注册列表即版式序 | 构建脚本的 STRUCTURE 列表决定书的拼接顺序 | 排版 03 |
| 出版折算 | 字数对外口径：汉字 + 英文单词 + 连续数字串 | 排版 05 |
| 三端一致 | 版权页版本号 == 根 README tag == 落地页 PDF 链接版本号 | 排版 05 |
| 长尾收益 | 收益 = 概率 × 影响；小概率大损失用确定性规避，如开源字体选型 | 排版 04 |
| 字体收敛 | 正文/等宽全部收敛到 @font-face 注册的开源族（SourceHanPrint / SourceHanMono，双思源 + SourceSans3 Latin 兜底），删本地字体领头——防 CFF 与本地 TTF 混排触发 Chromium 子集化失效、正文回退版权字体 | 排版 04 |
| 内容盒（ICB） | print 布局的可用宽度基准，A4@96dpi 实测 ≈672px；内容超出即触发 Chromium 整本等比压缩，body 收 665px 留 7px 安全 | 排版 04 |
| 整档缩放 | 内容超内容盒时 Chromium 把整本等比缩小（shrink-to-fit，正文 12pt→10.7pt 级事故）；修复 = 消除触发源（border-box / 断行 / 665px）+ 树形图按需 zoom | 排版 04 |
| 目录页码列 | 目录行右侧页码/虚线/链接区的几何约束——页码右对齐基线 538、虚线终点 ≤521、链接区右缘 ≤543，三项耦合防穿 .toc 装饰框 | 排版 04 |
| 规范之家 | 族系全部规范的唯一存放地（typesetting/）：三规范各司其职、文件名统一 X_GUIDE 惯例、各仓不持有规范文件、旧文件归档优于删除——每条规则只有一个定义点 | 排版 06 |
| 脚本即规范 | 排版规则的 py 化固定：清洗/口径/几何由脚本硬编码必然执行，条文与代码实时一致，改脚本 = 改规范 = 全量 rebuild | 排版 07 |
| 产物实证扫描 | 管线变更后对产物逐项实测（残留全零/页码入框/章数一致），"改了"不等于"改对了" | 排版 07 |
| 明确位置 | 任务执行中随时可答"执行到哪一步"；处理只挂在一个环节、门禁失败只回退到对应环节，loop 只在该 loop 的地方发生 | 排版 08 |
| 对齐粒度 | 相似子任务用同一副尺子切分；收口到统一处理点（一处修，不遍地补丁），压住随机误差 | 排版 08 |
| 穷举正反例 | 偏差出现时纠偏一次到位：事故登记册 + 单测固化反例，查表执行不现场瞎试 | 排版 08 |
