# Typesetting — 排版规范与排版解析册

> wUwproject 的 AI 成书排版规范与排版方法论文档集。CC BY-SA 4.0。

## 仓库定位

本目录是书族系**规范之家**，收录全部族系规范与排版方法论：单篇写作规范（STYLE_GUIDE）、转化入书规范（STRUCTURE_GUIDE）、书籍结构规范（BOOK_GUIDE）与成书排版系列文章（articles/）——三份规范各司其职，族系唯一，各仓不持有规范文件。2026-09-01 自仓库根拆出并汇编姊妹册，规范文件历史提交保留（git mv）。

## 排版解析（姊妹卷）

本目录 6 篇排版方法论文章已汇编为册子《**我思故我写 · 排版解析——五层排版如何把一篇文章变成一本书**》（typ-v1.2.0，约 2.4 万字，CC BY-SA 4.0）——母书《我思故我写》的姊妹卷：母书回答"为什么"、架构解析册回答"怎么做"、本册回答"怎么排"。

收录内容：版权页 + 导读（五层排版路径 + 映射表）+ 排版 01~06（源稿 / 元素 / 骨架 / 页面 / 元数据五层排版 + 收束篇「AI 任务执行的完整流程」）+ 附录 A 统一术语表 + 附录 B 排版速查。

**册子的在线阅读、下载（PDF / HTML / EPUB）与构建入口统一见 [`book/README.md`](book/README.md)。**
