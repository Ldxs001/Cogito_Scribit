# 规范地图（SPEC MAP · Cogito 书族系 · v1.1）

> 渐进式入口：本文件**不承载任何规则条文**，只回答"做这件事，读哪几节"。细则全部在三份规范里，每条硬规则按**四件套**成立——条文 + 判据（可测量）+ 正例 + 反例（判例）；无反例不成规则（准入见 BOOK_GUIDE §五）。
> 规范之家 = `typesetting/`：全部规范唯一存放本目录，各仓不持有规范文件，旧文件归档 `archive/`。
> 冲突裁决：**书籍结构（BOOK_GUIDE）＞ 转化（STRUCTURE_GUIDE）＞ 单篇（STYLE_GUIDE）**。

## 三、规范自身的治理（方法论锚定：用母书方法论规范规范）

**规范里的每条规则、每个术语都是名词，守母书 09f：名词不解释就等于没有名词。** 四件套不是新发明，是 09f 四维展开在规范条文上的工程同构：

| 09f 四维展开 | 规范工程形态（四件套） | 失效症状（09f 实证迁移） |
|---|---|---|
| 解释划界 | 条文：说清该怎样 | 无边界，执行在界内随机游走 |
| 细化收窄 | 判据：可测量的线 | 半径失控，"差不多合规"无法判 FAIL |
| 举例锚定 | 正例：合格长什么样 | 有界无轴线，方向不确定 |
| 反例削峰 | 反例：判例入库定 FAIL | **最近竞争义项抢采样**——版本日志的最近竞争义项是更新日志体，不点名压制它必然复发（typ-v1.2.0 判例即此机制） |

- **规则准入**（锚点：母书 08a 前置规范大于后置验证）：新规则入三份规范必须带四件套，无反例不成规则——判据写不出测量线的规则是标语，不许入规范；准入卡在**入规范之前**。前置规范只能防自觉（08a），后置验证防幻觉不可替代（08b）——rebuild 门禁 / 产物实证扫描照常执行，两层分工不互相替代
- **名词纪律**（锚点：母书 09f）：跨文件引用的术语必须有**定义点**——该术语在规范之家内的唯一解释位置（本文件定义，或显式指向定义所在文件与节）；同名异义、异名同义都算义项混合，即 FAIL
- **判例入库**：事故即判例，随修复即时入库（反例注明日期与超标实测值）；存量标语级规则按本图 §二"存量/待补"标记，动到时补齐
- **修订动作**（锚点：母书 01 硬约束——LLM 的自觉是负资产）：改规范 = 改规范文档 + 受影响脚本 + 受影响册全量 rebuild + 本文件索引行核对

## 四、方法论符合度矩阵（母书 21 篇 → 规范体系，逐篇对账）

> 本表是"用方法论规范规范"的对账单：每篇方法论在规范体系中的体现点与锚定状态。**体现**=机制已在规范中运行；**锚定**=体现点显式标注了方法论出处。未锚定的动到时补标（存量待补惯例）。

| 方法论（母书） | 规范体系中的体现点 | 状态 |
|---|---|---|
| 01 硬约束架构（LLM 的自觉是负资产） | 脚本即规范（build/ 六脚本）；改规范=改文档+改脚本+rebuild | §三已锚定 |
| 02 构建时契约 | 规则准入四件套=规则入规范前的形态契约 | §三已锚定 |
| 03 递归自举（不约束自己就没资格约束别人） | 治理章管规范自身：准入/名词纪律先约束规范条文再约束书 | §三+本表（自举记录） |
| 04 技能流水线编排 / 05 链驱动执行 | build/ 管线确定性执行，LLM 只做写作与决策两头 | 体现未标 |
| 06 领域智能体（RAG） | 不适用（领域层，非规范对象） | —— |
| 07 架构的减法与约束的加法 | 不复制产生第二份口径（减法）+ 门禁与准入（加法） | 体现未标 |
| 08 有限决策范式（LLM 只填空不决策） | §一角色路径=填空域：做哪件事只读哪几节，读什么已穷举 | 本图 §一 |
| 08a 前置规范大于后置验证 | 规则准入卡在入规范之前 | §三已锚定 |
| 08b 填空的边界（后置验证防幻觉不可替代） | rebuild 门禁 / 产物实证扫描（后置）与准入（前置）分工 | §三已锚定（本版修复张力） |
| 08c 槽位的减法 | 清洗规则表 / 单篇固定模板的枚举槽位 | 体现未标 |
| 09 穷举的宿命（边界由人画） | 规范=穷举成文；管什么/不管什么由分工表画界 | 体现未标 |
| 09a 探测的边界 / 09c 天然不对等 | 不适用（RAG 检索/语义层） | —— |
| 09b 配置推动的穷举一致性（统一推动点位） | 改规范三联动=统一点位（文档/脚本/rebuild 一处推动） | 体现未标 |
| 09d 细碎处理与区域重构的成本切割 | 细碎是 py 的特权（几何数值/清洗判据在脚本），叙述是 LLM 的正道 | 体现未标 |
| 09e 提示词拉扯的边界 | STYLE_GUIDE 版式与模板=结构性指令重塑写作分布 | 体现未标 |
| 09f 名词不解释就等于没有名词 | 四件套 + 名词纪律（定义点） | §三已锚定 |
| 10 / 10a / 10b 认知重估 | 不适用（哲学层，非工程规范对象） | ——

**对账结论（2026-09-04）**：机制层大半已在遵守（规范体系本就按方法论建成），锚定层不全——已锚定 6 篇、体现未标 7 篇、不适用 6 篇；未锚定项动到时补标，新规则准入时按 §三同步标注锚点。
