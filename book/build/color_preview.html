相同层级相同颜色，文字颜色不变，亮暗自适应。全部对比度 WCAG AAA（light 14.4~14.7:1 / dark 9.7~10.2:1）

四、纯文本 / 行内代码 / 代码框 / 公式（不受层级色影响）

这是纯文本段落：提示词变了，条件变了，整条链上每一个后续 token 的分布全部跟着变。引用自{文件名} 是行内代码标记。

# 代码框（pre）
def pipeline(nodes):
    for n in nodes:  # 遍历
        execute(n)
P(至少一次幻觉) = 1 - (1-p)N

行内公式：计算预算约束可表述为 C ≈ N × T（FLOPs），缩放定律损失 L ∝ Nα。
